# Portable self-media contract references

This Apache-2.0 first-party distribution contains generic schemas, proposed
source-byte bindings, frozen consumer copies and synthetic examples. The seven
contract IDs and facade meanings are preserved. This is metadata, not a new
registry, router, research platform, renderer, worker or business state machine.

| ID | Included | Runtime boundary |
| --- | --- | --- |
| material-manifest.v1 | WCF ordered-document binding; VKP compatibility reference; synthetic envelope | Native source/temporal semantics remain with their Owners; optional ebook adapter omitted |
| evidence-bundle.v1 | Public QRP canonical schema/fixture and ARW adapter references | Source hashes do not verify research facts or end-to-end interoperability |
| content-brief.v1 | Current Studio schema bindings; frozen synthetic video brief/schema | Native payloads and manual author approval remain unchanged |
| review-packet.v1 | Original normalized-view meaning and public frozen intake schema reference | Optional attention/lifecycle Owners not distributed; native integration blocked |
| service-profile.v1 | Generic schema, synthetic example, current ARW compatibility reference | A historical fixture marked fresh is not current service health |
| closure_run.v1 | Original local-tool-closure-run.v2 schema and synthetic shape example | No closure engine, real fingerprints, queue or completion proof |
| local-tool-event.v1 | Generic event schema and synthetic event | No event transport, delivery proof or execution permission |

The legacy `mainchain_manifests` field contains seven descriptors of actual
selected source interfaces: QRP, ARW, the main content workflow, VKP, MVP,
Gateway and this inspector. It does not declare an installed or running chain.
Descriptor IDs/commands are metadata only. Empty contract refs mean that this
distribution makes no native consumption claim. The MVP descriptor identifies
an unpublished candidate explicitly; it is not a public installation URL.
The bundle format's seven-descriptor count is not a discovery result or a
replacement for a private tool inventory.

`sources/public-toolchain.lock.json` is an unchanged published metadata snapshot.
Its earlier pins and unavailable entries are retained as history, not presented
as today's deployment. Proposed source bindings in the catalog carry their own
exact commits/hashes. `registry_sha256` is the legacy field for that snapshot's
digest; no operational registry was created. The empty difference queue applies
only to this selected metadata subset, not to remaining private tools or audits.

All compatibility rows remain proposal-only or blocked. `AVAILABILITY.json`
records per-contract limitations. The review packet still means a short native
attention review with lifecycle completeness rules; neither a ContentStudio
case receipt nor a QRP candidate pack establishes that integration. Missing,
invalid or unreviewed inputs cannot acquire author approval from this package.

`governance-bundle` validates local schema/hash consistency with no network or
tool execution. It checks four self-contained synthetic example schemas; it
does not fetch their invented fingerprint paths/fixture URIs, validate actual
research, run native review, assess freshness today or verify lifecycle changes.
The frozen video schema has the same parsed JSON object as the current public
Studio schema but different serialization bytes; their raw hashes remain
distinct. Main's current public `validate_public_content_owner` binds Studio's
content-item schema to its equal shared copy. It does not equate either with an
older, differently hashed schema.

Root and installed resource copies are byte-identical. Artifact
`exact_generated_snapshot` describes bytes within this generated distribution,
not an assertion that adapted files equal upstream. `SOURCE-PROVENANCE.json`
records original and distributed hashes, changes and licenses. Original generic
schema bytes are retained; adapted catalog/wrappers/fixtures and new descriptors
are marked by this notice and provenance. No AGPL implementation, private
inventory, operational receipt, user content, font, music, model or binary is
copied. External source references keep their native licenses and ownership.
